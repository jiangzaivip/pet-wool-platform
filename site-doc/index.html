项目文档

羊毛毡宠物定制平台

一个面向跨境手工定制业务的网站系统，包含用户前端和后端管理端。当前版本已经覆盖商品展示、照片上传下单、PayPal 真实支付跳转确认、用户“我的订单”、客服入口、博客/政策内容，以及中文管理端的订单、商品、分类、用户、站点和支付配置。

客户使用流程

  • 浏览首页、分类、商品详情、护理 FAQ、博客和客户评价。
  • 选择规格和定金/全款，上传宠物参考照片并提交订单。
  • 通过 PayPal 创建、跳转和确认支付；支付暂不可用时可进入“我的订单”继续处理。
  • 使用下单邮箱登录“我的订单”，查看进度、尾款、物流、参考照片和售后客服入口。

管理端交付范围

  • 中文管理端：概览、用户管理、分类管理、商品管理、订单管理、站点配置。
  • 订单运营：筛选、导出、交付清单、异常标记、状态流转、付款记录和物流事件。
  • 站点配置：品牌信息、客服 TALK/LINE、PayPal Client ID / Secret / Webhook ID、政策、FAQ、评价和博客。
  • 数据安全：脱敏备份、完整密钥备份二次确认、站点配置恢复、命令行备份恢复和上传引用清理。

01

产品需求

用户前端

  • 品牌首页：首屏介绍、卖点、作品图。
  • 商品展示：展示定制类型、价格、定金比例和规格。
  • 定制流程：上传照片、确认细节、手工制作、预览发货。
  • FAQ：展示常见问题，降低客户咨询成本。
  • 下单表单：提交客户信息、宠物信息、照片 URL 和备注。

后端管理端

  • 管理员登录：邮箱和密码登录后台。
  • 订单管理：查看订单并修改订单状态。
  • 商品管理：维护商品价格、图片、排序和中文内容。
  • FAQ 管理：维护中文问题和答案。
  • 站点配置：维护主题、品牌和订单规则。
角色目标核心操作
客户了解定制服务并下单浏览、选择商品、提交订单
管理员处理订单和内容维护登录后台、管理订单、维护商品
运营人员更新展示内容调整价格、FAQ、中文文案和站点配置

1. 联系方式与机器人客服

客户问题联系方式能不能添加机器人回答？语言按地区自动搜索。
建议方案增加在线客服入口，支持机器人 FAQ 自动回复；根据浏览器语言或 IP 地区自动切换语言，并允许用户手动切换。

Admin Plan

后端整体实现方案
