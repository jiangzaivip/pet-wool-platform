项目文档

羊毛毡宠物定制平台

一个面向跨境手工定制业务的网站系统，包含用户前端和后端管理端。当前版本已覆盖商品展示、宠物照片上传下单、PayPal 支付、用户“我的订单”、客服与 AI 机器人、博客与政策内容，以及管理端的订单、商品、分类、用户、站点和支付配置。

Delivery

当前可交付功能

客户使用流程

  • 浏览首页、分类与子分类、商品详情、护理 FAQ、博客和客户评价。
  • 选择规格与定金/全款/尾款，上传宠物参考照片并提交订单。
  • 通过 PayPal 创建支付单、跳转授权并捕获确认。
  • 登录“我的订单”查看制作进度、尾款、物流单号与售后客服入口。

管理端交付范围

  • 概览、用户管理、分类管理、商品管理、订单管理、站点配置、审计日志。
  • 订单运营：搜索筛选、导出、交付清单、异常标记、状态与付款流转、物流事件。
  • 站点配置：品牌、联系方式、PayPal Client ID / Secret / Webhook ID、政策、FAQ、评价、博客、主题配色。
  • 数据安全：脱敏备份、完整密钥备份二次确认、配置恢复、命令行备份恢复与上传引用清理。

Capability

功能清单

用户前端

  • 首页 Hero、制作流程、客户评价、信任信息与主题色板切换（White / Cream / Sage / Rose / Dark）。
  • 大分类、子分类、Occasion / Style 筛选与商品详情 SEO、FAQ、ALT 文本、Product JSON-LD。
  • 宠物照片上传：JPEG / PNG / WebP，单文件 8 MB、最多 12 张，校验文件签名。
  • 订单草稿保存、重复提交幂等（client_request_id）、商品/规格/金额/客户信息校验。
  • 多语言界面与内容回退；robots.txt 与 sitemap.xml 随站点动态生成。

支付与数据

  • PayPal Orders API：创建支付单、捕获、Webhook 验签与幂等；开发环境可走本地 mock。
  • 多币种：价格以 KRW 为基准，按固定汇率换算 USD / CNY 展示，PayPal 以站点配置币种收款。
  • 支付记录同时保存基准金额快照与实际收款金额，尾款按汇率版本分配取整差额。
  • 数据主源为 JSON 文件，PostgreSQL 为可选后端；支持备份、恢复校验和测试数据清理。

Deployment

部署说明

生产环境

  • 域名：https://woolbuddy.shop（HTTPS）
  • Node 单体服务同时提供前端静态与 API，nginx 443 反代到 127.0.0.1:8888。
  • 发布方式：deploy.sh，自动构建、远端检查、systemd 重启、健康检查与 smoke。
  • 数据文件：api-node/data/store.json（PostgreSQL 为可选后端）。
