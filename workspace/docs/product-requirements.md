# 产品需求文档

## 1. 项目目标

为羊毛毡宠物定制业务提供一个可展示、可下单、可管理的 MVP 系统。系统支持中文、英文、韩文三种语言，适配跨境手工定制业务中的商品展示、定金下单、订单跟进和后台内容维护。

## 2. 用户角色

| 角色 | 目标 | 核心操作 |
| --- | --- | --- |
| 访客/客户 | 了解定制服务并提交订单 | 浏览首页、查看商品、阅读 FAQ、提交定制订单 |
| 管理员 | 管理订单和运营内容 | 登录后台、处理订单、维护商品、维护 FAQ、配置站点 |
| 运营人员 | 更新展示内容和定制规则 | 调整商品价格、主题、多语言文案、FAQ |

## 3. 用户前端范围

### 首页

- 品牌首屏展示。
- 可信卖点展示。
- 商品列表展示。
- 定制流程说明。
- FAQ 展示。
- 跳转下单入口。

### 下单页

- 选择商品。
- 填写客户信息。
- 填写宠物信息。
- 选择定金、尾款或全款。
- 填写照片 URL 和备注。
- 提交后返回订单号。

### 多语言

- 支持 `zh`、`en`、`ko`。
- 商品和 FAQ 从后端按语言读取。
- 页面静态文案由前端 i18n 管理。

## 4. 后端管理端范围

后端在本项目中按“管理端后台系统”规划，包含后台 UI 和管理 API。

### 登录

- 管理员使用邮箱和密码登录。
- 登录成功后返回 token。
- token 存储在浏览器 localStorage。

### 订单管理

- 查看订单列表。
- 查看客户信息、宠物信息、支付类型、金额和创建时间。
- 修改订单状态。
- 状态包括：`new`、`confirmed`、`crafting`、`preview`、`balance_due`、`shipped`、`completed`、`cancelled`。

### 商品管理

- 创建商品。
- 维护价格、币种、定金比例、排序、图片。
- 维护中文、英文、韩文标题和描述。
- 后续应补充编辑、上下架、删除、规格管理。

### FAQ 管理

- 创建 FAQ。
- 维护排序。
- 维护中文、英文、韩文问题和答案。
- 后续应补充编辑、启停和删除。

### 站点配置

- 维护默认主题。
- 维护可用主题列表。
- 后续应补充品牌名、联系邮箱、社交账号、SEO 配置、订单规则。

## 5. 非目标范围

MVP 暂不包含：

- 在线支付真实扣款。
- 图片文件上传和对象存储。
- 邮件通知。
- 物流系统对接。
- 复杂权限角色。
- 内容 CMS 全量能力。

## 6. 后续优先级

1. 接入正式 PostgreSQL，替换临时 JSON 数据服务。
2. 接入对象存储，用于宠物照片上传。
3. 完善管理端编辑、删除、上下架能力。
4. 增加订单详情页和内部备注。
5. 增加邮件通知与支付链接。
6. 增加仪表盘统计。
